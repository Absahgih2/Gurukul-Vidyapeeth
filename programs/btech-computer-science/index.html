Program Overview

The B.Tech in Computer Science & Software Engineering program is co-designed directly with software engineers and industry veterans. Instead of outdated theoretical curriculums, students engage in practical programming labs starting from semester one. You will master full-stack software development, distributed systems architecture, CI/CD automated deployments, and MLOps pipelines.

Year-by-Year Syllabus

Year 1: Programming & Web Fundamentals

Introduction to Python/C++, Object-Oriented paradigms, HTML5, CSS Grid/Flexbox, JavaScript fundamentals, Git version control, and engineering mathematics.

Year 2: Core Computer Science & Databases

Data Structures & Algorithms (DSA), Relational & NoSQL Databases (PostgreSQL, MongoDB), Operating Systems core, Computer Networks, and API designs (RESTful microservices).

Year 3: Distributed Systems & Cloud/DevOps

Cloud computing environments (AWS, Azure), Docker containerization, Kubernetes orchestration, CI/CD deployment pipelines, system security, and software testing automation.

Year 4: Machine Learning Ops (MLOps) & Capstone

Machine learning models, Neural Networks, Generative AI integration, enterprise MLOps, software product scaling, and a mandatory 6-month industry internship with a capstone project.

Career Pathways

Graduates are fully prepared to enter the tech sector directly with zero retraining. Typical roles include:

Cloud Systems Architect
Full-Stack Software Engineer
DevOps & Infrastructure Engineer
ML / AI Operations Specialist
